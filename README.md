## How to Add the Repository

1. Open **Sileo** (recommended) or Zebra.
2. Tap **Sources** → **+** (Add Source).
3. Paste the following URL:
   ```
   https://opticalraze.github.io/repo
   ```
4. Tap **Add Source**.

Once added, you can browse and install all Optical Raze tweaks.
