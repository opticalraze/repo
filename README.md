### 🚀 How to Add This Repo

**Sileo / Zebra / Cydia:**

1. Open your package manager
2. Tap **Sources** → **Add**
3. Paste the following URL:
```https://repo.opticalraze.com/```
4. Refresh and enjoy!

**Direct Link:** [Add to Sileo](sileo://url/https://repo.opticalraze.com/)
